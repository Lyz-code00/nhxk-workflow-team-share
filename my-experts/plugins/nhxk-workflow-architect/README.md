# 工作流架构师（nhxk-workflow-architect）

面向 NHXK/PPP 低代码工作流平台的架构设计专家：核证平台源码与能力边界，把已确认需求转化为可落地的开发方案与按依赖排序的任务清单。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **能力核证**：按能力地图定位本次受影响的后端锚点（Controller / Service / DO / VO）、CUSTOM 公共契约、前端组件与迁移目录，记录实际路径与读取依据。
- **模式判定**：默认 NORMAL，先核对平台能力；独立业务存储、列表或集成需求触发能力评估，给出"扩展 NORMAL"或 CUSTOM 方案，不自动切换、也不裁剪需求。
- **需求 → 能力对应**：产出 `需求编号 | 当前能力及证据 | 缺口 | 推荐实现 | 待确认项`，把业务口径缺口集中提出，不猜规则。
- **方案落盘**：写出 `02-开发方案.md`（字段/数据/接口/页面/流程绑定/权限/事务/验收对应/风险）与 `03-开发任务清单.md`（按真实依赖排序、含完成标准），并更新 `docs/workflow/00-任务索引.md` 与方案状态。
- **交接**：给出文件链接、修订号、阻塞项、下一责任角色与首项开发任务。

## 内置技能

`skills/nhxk-workflow-design/`，随包携带 `references/workflow-standards/` 完整公共标准（10 份）：

| 文档 | 用途 |
|---|---|
| 共同约定 | 范围、授权、默认模式与角色交接 |
| 需求契约 | 业务要点、确认单与验收边界 |
| 专项需求检查 | 周期数据、自动取数、文书、附件等条件性规则 |
| 技术设计标准 | 能力评估、数据/接口/流程设计 |
| 能力地图 | 当前平台源码与公共契约定位 |
| 实现与验证清单 | NORMAL/CUSTOM 分层产物及检查 |
| 测试与留痕标准 | 自动化、运行证据与缺陷交付 |
| 审核标准 | 审核内容、问题和结论 |
| 任务文档与交接标准 | 固定目录、编号顺序、方案落盘、版本与角色交接 |
| 文档目录 | 标准文档总览 |

## 使用示例

- 根据当前需求草案，输出可落地的开发方案和按依赖排序的开发任务清单。
- 核对这次需求涉及的平台源码、表单/流程绑定与能力缺口，给出 NORMAL/CUSTOM 实现边界。
- 审查已有开发方案与任务清单，指出阻塞项、待确认业务口径和验证重点。

## 安装

将专家包目录放到专家目录下：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/nhxk-workflow-architect/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
