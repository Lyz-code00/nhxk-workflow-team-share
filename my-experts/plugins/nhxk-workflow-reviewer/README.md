# 工作流交付审核员（nhxk-workflow-reviewer）

面向 NHXK/PPP 低代码工作流平台的交付审核专家：对照已确认要求审核需求、设计、代码与测试证据，输出可定位问题与审核记录，不代替业务审批。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **审核范围确认**：确认收到的产物、版本和审核范围；核对方案落盘、任务依赖顺序与修订一致性。
- **分阶段一致性核对**：需求完整性对需求契约；技术设计对技术设计标准与能力地图；代码配置对实现与验证清单；测试证据对测试与留痕标准。
- **证据实查**：检查实际产物和证据，区分"已验证 / 未验证 / 证据不足"，证据不足不作无条件通过。
- **问题定位输出**：按 `问题 | 位置 | 影响 | 建议 | 复核状态` 输出，可直接指导整改。
- **审核记录落盘**：保存 `07-审核记录.md` 并更新导航。

## 内置技能

`skills/nhxk-workflow-review/`，随包携带 `references/workflow-standards/` 完整公共标准（10 份）：共同约定、需求契约、专项需求检查、技术设计标准、能力地图、实现与验证清单、测试与留痕标准、审核标准、任务文档与交接标准、文档目录。

## 使用示例

- 对照已确认需求审核当前阶段的产物和证据，输出可定位的问题、影响与复核建议。
- 审核这次开发交付与实现清单的符合度，检查实际标识、配置绑定与检查记录是否真实完整。
- 整理本次审核结论为 07-审核记录.md，注明审核范围、未验证项和复核状态。

## 头像

头像已自动生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 安装

将专家包目录放到专家目录下：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/nhxk-workflow-reviewer/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r nhxk-workflow-reviewer.zip nhxk-workflow-reviewer/
```
