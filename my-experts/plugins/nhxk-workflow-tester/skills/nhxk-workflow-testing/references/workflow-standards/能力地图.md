# 当前能力地图

用本地图定位当前实现；只核对本次任务相关路径。以当前 POM、源码和迁移为准，不将地图中的能力描述当作已验证事实。

## 能力边界

平台当前支持：

- NORMAL 动态表单：以 form-create 配置与字段 JSON 持久化；
- Flowable 建模、校验、部署、实例发起、任务审批与历史；
- CUSTOM 业务表单注册、摘要快照、统一发起、参与者只读权限与条件状态回写；
- 单文件人工验收页：动态建模绑定、发起、任务详情与业务状态回写。

平台当前不提供"自然语言一键生成表单并部署流程"的应用页面或服务。生成由主实现 AI 助手经本 skill 完成；数据库与部署操作仍需显式授权。

## 不可协商的铁律

- `formCode` 与 `processDefinitionKey` 在已注册 Provider 中全局唯一。
- Provider 发起/查看路径与模型元数据保持一致。
- 本单 JAR 项目业务代码依赖 `nhxk-module-bpm`，通过 `api.*` 公共契约调用工作流能力，并允许复用现有状态枚举；不依赖内部 Service/Mapper。
- CUSTOM 的业务字段留在业务表；只把路由/审批变量传给 Flowable。
- 提交前先锁行；仅当事件实例与当前绑定匹配时才更新状态。
- 工作流详情读取须核对当前流程绑定与归属/参与者授权；普通业务端点保留各自的权限校验。
- 绝不直写 Flowable `ACT_*` 表。
