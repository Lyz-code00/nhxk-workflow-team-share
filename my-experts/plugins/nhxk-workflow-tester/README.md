# 工作流测试工程师（nhxk-workflow-tester）

面向 NHXK/PPP 低代码工作流平台的测试专家：设计并执行 E2E、接口验证、回归与缺陷复现测试，按需求编号留证，缺陷闭环后输出验收报告。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **测试输入核对**：读取确认需求、交付说明与目标版本，证据对应实际代码/模型版本。
- **用例设计**：把需求编号对应到用例、预期和证据；未决业务规则标待确认，不猜预期。
- **多层级执行**：复用现有工具链执行 E2E、接口验证、回归、缺陷复现，以实际状态、数据及权限结果验证。
- **测试条件核对**：按实现与验证清单核对开发交付是否具备测试条件。
- **留痕与报告**：落盘 `05-测试方案.md`、`06-测试报告.md`，按运行编号交接证据和缺陷。
- **缺陷修复闭环**：发现问题直接提交开发人员修复，复测直到用例全部通过，缺陷状态追踪到终态。
- **验收报告输出**：缺陷闭环通过后，按需求文档验收标准逐条映射用例与运行证据，落盘 `09-验收报告.md` 给出最终验收结论；未覆盖/待确认条目如实标注，不写假通过。

## 内置技能

`skills/nhxk-workflow-testing/`，随包携带 `references/workflow-standards/` 完整公共标准（10 份）：共同约定、需求契约、专项需求检查、技术设计标准、能力地图、实现与验证清单、测试与留痕标准、审核标准、任务文档与交接标准、文档目录。

## 使用示例

- 根据已确认需求和开发交付设计本次测试方案，把用例对应到需求编号和验收标准。
- 执行本轮测试并按运行编号留证，区分实际通过、失败、跳过、阻塞与未执行，写 06-测试报告.md。
- 缺陷闭环通过后，按需求文档验收标准逐条映射证据，输出 09-验收报告.md。

## 安装

将专家包目录放到专家目录下：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/nhxk-workflow-tester/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r nhxk-workflow-tester.zip nhxk-workflow-tester/
```
