# NHXK 工作流交付团队 · 安装说明（同事适用）

> 适用：Mac 与 Windows 均可。安装后即可在 WorkBuddy 中使用六人工作流团队（总调度+需求/架构/开发/测试/审核）。

## 一、前置条件

1. 已安装 **WorkBuddy**（客户端）
2. GitHub 可访问（拉取本插件包）；后端仓库 ppp-oms-backend 从你们内部 Git 获取
3. 已 clone 后端仓库 `ppp-oms-backend`（任务文档写在它的 `docs/workflow/` 下）

## 二、获取插件包

从 GitHub 拉取本仓库（公开地址见仓库主页 Clone 按钮），得到目录结构：

```
my-experts/
├── .codebuddy-plugin/marketplace.json
└── plugins/            ← 7 个插件（六角色团队 + 5 个单角色包）
```

## 三、安装（按你的系统二选一）

### Mac
把整个 `my-experts` 文件夹放到：
```
~/.workbuddy/plugins/marketplaces/my-experts
```
（访达按 `Cmd+Shift+G`，输入 `~/.workbuddy/plugins/marketplaces/` 回车，把文件夹拖入）

### Windows
放到：
```
%USERPROFILE%\.workbuddy\plugins\marketplaces\my-experts
```
（资源管理器地址栏粘贴 `%USERPROFILE%\.workbuddy\plugins\marketplaces\` 回车，把文件夹拖入；没有 `marketplaces` 目录就新建）

> 包内所有文档路径均使用 `~/` 写法：Mac 上即你的用户目录；Windows 上对应 `C:\Users\你的用户名\`。涉及具体文件路径时按此对应即可。

## 四、放参考包（需求生成功能需要）

苏澄（需求分析师）生成原型时会参照两个真实项目包。把仓库里的参考包放到你的用户目录：

- Mac：`~/Work/weekly-operation-report/` 与 `~/Work/monthly-operation-report/`
- Windows：`C:\Users\你的用户名\Work\weekly-operation-report\` 与 `...\monthly-operation-report\`

> 不放也不影响其他阶段（架构/开发/测试/审核），只有"需求正向生成原型"模式用到。

## 五、验证

1. 重启 WorkBuddy
2. 左侧栏 →「专家」→ 找到 **「NHXK工作流交付团队」**
3. 开对话发一句"读一下任务索引"——总调度能读到你本地 ppp-oms-backend 的 `docs/workflow/00-任务索引.md` 即安装成功（注意：任务文档以你本机 clone 的后端仓库为准）

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 专家列表里找不到团队 | 检查目录层级：必须是 `marketplaces/my-experts/plugins/...`，别多套一层 `my-experts/my-experts` |
| 总调度说找不到任务索引 | 你本机的 ppp-oms-backend 还没 clone，或 clone 到了非约定路径——把仓库路径直接告诉总调度即可 |
| Windows 下路径对不上 | 文档里的 `~/` = `C:\Users\你的用户名\`，按此换算 |

## 七、升级

插件包有更新时：重新拉取 → 覆盖 `marketplaces/my-experts` → 重启 WorkBuddy。你自己在任务文档里的数据（后端仓库 docs/workflow/）不受影响。
