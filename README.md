# NHXK 工作流交付团队 · 分享包

六人 AI 交付团队（总调度 + 需求/架构/开发/测试/审核），用于 NHXK/PPP 低代码工作流平台的功能交付：从需求梳理 → 架构方案 → 用户门控 → 编码与数据库 → 测试缺陷闭环 → 审核验收的全流程。

## 仓库内容

| 目录 | 说明 |
|---|---|
| `my-experts/` | WorkBuddy 插件包（六角色团队 + 5 个单角色包 + 共享标准文档） |
| `weekly-operation-report/` | 参考包：运营周报（原型 + 需求文档，苏澄范式的依据） |
| `monthly-operation-report/` | 参考包：运营月报（原型 + 需求文档 + Word 模板） |

## 快速开始

1. 按团队协作流程 clone 本仓库
2. 阅读 `my-experts/安装说明.md`（Mac / Windows 双系统安装指引）
3. 参考包放到用户目录 `~/Work/` 下（安装说明第四节）
4. 重启 WorkBuddy → 专家列表选择「NHXK工作流交付团队」

## 首个实战案例

本团队已完成运营周报 + 运营月报两个模块的真实交付（CUSTOM 业务表单全链路：建表 / 后端分层代码 / 前端三件套 / 审批流部署 / E2E 验证）。任务文档与证据链范本见交付仓库 `docs/workflow/tasks/`（内部 Git，不在本仓库）。
