# 运营周报管理需求文档

> 所属模块：运营管理  
> 需求来源：《某PPP项目一体化智慧运营管理平台建设方案》§2.3.2；本轮按周报填报口径细化。  
> 文档状态：本轮页面字段、列表展示与附件交互已明确；接口统计口径和流程细节待联调确认。

## 1. 功能

运营周报管理用于按时间区间登记项目运营回款、本周运营情况及下周工作重点，并支持查询、审批和附件归档。

## 2. 功能说明

业务信息统一归入“周报信息”，字段顺序为：项目标题、时间区间、项目运营回款、项目运营情况、下周工作重点、附件。附件是周报信息的最后一个字段，不另设附件分组。

主要业务流程：填报 → 部门负责人审核 → 申请人确认 → 归档。

## 3. 字段说明

系统固定字段沿用平台规范，包括 id、创建人、创建时间、更新人、更新时间、创建部门和创建机构。以下英文字段名为逻辑标识，数据库建模时需统一复核。

| 中文字段名  | 英文字段名              | 数据类型      | 必填 | 说明                                                                    |
| ------ | ------------------ | --------- | -- | --------------------------------------------------------------------- |
| 项目标题   | weeklyTitle        | String    | 是  | 单行文本；周报信息第一个字段                                                        |
| 时间区间   | weeklyPeriod       | DateRange | 是  | 起止日期使用年月日选择控件；开始日期不得晚于结束日期；列表格式为“XX年YY月ZZ日到XX年YY月ZZ日”                 |
| 项目运营回款 | weeklyField01      | String    | 是  | 多行文本框，首句默认“1.本周运营回款\__\_万元。”；系统按所选时间区间汇总费用收款登记中的收款金额并回填，见新增/编辑页开发补充说明 |
| 项目运营情况 | weeklyField02      | String    | 是  | 多行文本框                                                                 |
| 下周工作重点 | weeklyField03      | String    | 是  | 多行文本框                                                                 |
| 附件     | weeklyAttachment01 | File[]    | 否  | 可上传多个附件；按钮文字“点击上传”，提示“非必填，可上传多个附件。”；无附件显示“暂无附件”                       |

列表及流程元数据包括项目名称、所属公司、申请人、提交时间、流程节点和状态，由关联项目及流程信息带出。

## 4. 页面布局与交互

### 4.1 列表页

- 查询条件：时间区间、项目名称、所属公司、申请人、流程状态，支持组合查询和重置。
- 列表字段包含项目名称、时间区间、**本周运营回款**、申请人、提交时间、流程节点、状态和操作。
- 本周运营回款列只显示金额，格式为“XX万元”，不显示“1.本周运营回款”等文本；无有效金额时显示“—”。
- 时间区间显示为“XX年YY月ZZ日到XX年YY月ZZ日”。
- 支持新增、查询、重置、刷新及查看/编辑；刷新保留已应用的筛选条件。
- 总入口嵌入时展示完整业务模块导航，模块内容不显示重复的第二套菜单。

### 4.2 新增、编辑及详情

- 详情和编辑页业务分组标题均为“周报信息”，字段顺序为项目标题、时间区间、项目运营回款、项目运营情况、下周工作重点、附件。
- 项目标题为第一个字段。必填字段标题前以红色“*”标识；字段标题在对应填报控件之前。
- 新增、编辑和查看页面的项目标题、开始日期、结束日期三个输入框，分别与年度运营计划管理的“项目名称”输入框等宽，沿用其宽屏三列、中屏两列的宽度计算规则。项目标题及开始日期靠左与后续文本域起始位置对齐；两个日期框各自保持参考宽度，中间保留“到”及12px间距。控件高度、字体、边框和圆角沿用现有表单样式；620px及以下各输入框使用可用宽度，日期区间改为纵向排列。
- 查看和编辑页的“基本信息”区复用年度运营计划填报的字段、只读框、标题样式与分组边距：申请人、申请人联系电话、申请部室、所属单位、申请日期。宽屏三列、中屏两列、窄屏一列；系统带入字段沿用年度计划的必填标识规则，不额外标星。
- 周报业务字段标题和控件位于同一行。多行文本框标题固定在顶部首行，与普通 38px 高文本框标题处于相同高度，不在整个文本域高度内垂直居中；增加文本域高度不改变标题位置。
- 时间区间由开始日期和结束日期两个年月日选择控件组成一个逻辑字段。详情显示为“XX年YY月ZZ日到XX年YY月ZZ日”。
- 项目运营回款、项目运营情况、下周工作重点使用多行文本框。项目运营回款首句默认“1.本周运营回款\__\_万元。”。
- 新增、编辑页最底部按年度运营计划的说明格式展示浅灰底、左侧竖线的说明区域，标题为“开发补充说明：”，文案为：““项目运营回款”文本框首句默认显示“1.本周运营回款\__\_万元。”；系统根据所选时间区间，自动汇总费用收款登记中对应时间段的收款金额，并回填至首句中的金额位置。”只读详情页不显示该说明。
- 附件作为“周报信息”的最后一行，与字段在同一分组。行内显示上传按钮及上传图标、提示“非必填，可上传多个附件。”；没有文件时显示“暂无附件”。支持多文件选择。附件不标必填星号。
- 只读详情展示已保存的附件名称；没有附件时显示“暂无附件”。
- 只读态不提供保存、提交和删除操作。

## 5. 数据联动

系统根据所选周报时间区间及关联项目，汇总费用收款登记中对应时间段的收款金额，将累加结果自动回填至“1.本周运营回款\__\_万元。”的金额位置。纳入状态、日期匹配口径、单位换算、回填时点及无法匹配时的处理规则待接口设计确认。当前原型示例金额仅用于展示，不代表已连接实际数据。

## 6. 状态、权限与流程

状态及操作沿用本模块现行流程：草稿可编辑、删除和提交；审批中只读查看；已退回可编辑并重新提交；归档后只读查看。流程链为填报 → 部门负责人审核 → 申请人确认 → 归档。

流程图第一个业务节点为“部门负责人审核”，说明为“审核运营周报内容”；第二个节点为“申请人确认”。提交后列表流程节点为“部门负责人审核”；未提交记录显示“申请人”，已完成记录显示“—”。旧演示记录中的“权属企业审核”“城投公司审核”“法务审核”节点统一映射为“部门负责人审核”，保留原有业务内容。

部门负责人匹配方式、退回、撤回、时限、数据权限和提醒规则待统一确认。

## 7. 待确认事项

1. 费用收款登记回填金额的统计口径、匹配条件及更新时点。
2. 部门负责人匹配方式、附件类型及大小、数据范围和导出权限。
3. 字段长度及数据库字段名。

## 8. 验收标准

1. 列表展示时间区间和本周运营回款；回款单元格只显示“XX万元”。
2. 周报信息字段按项目标题、时间区间、项目运营回款、项目运营情况、下周工作重点、附件顺序展示。
3. 必填字段显示红色星号；附件为可选字段，并按指定上传按钮、提示和空状态呈现。
4. 日期可按年月日选择；开始晚于结束时提示并阻止提交。
5. 新增、编辑、详情、列表和总入口数据展示一致；回款开发补充说明只在新增和编辑页显示，文案与样式符合本文要求。
6. 独立入口和总入口流程图均展示“部门负责人审核 → 申请人确认”；列表待审核节点与流程图一致。
